# Two-minute hackathon demo

Use the **Sample workspace** for the full walkthrough. Its names, Calendar, Sheet, and Gmail are simulated in the browser; this script does not claim a live Google update.

1. **Open (0:00–0:15).** From the homepage, select **Try interactive demo**. Point out the explicit sample label and fictional-data notice. If this browser was used earlier and the event no longer starts at 2 pm, open **Demo controls** and select **Reset sample**.
2. **Ask (0:15–0:35).** Expand “Or describe the change in a sentence,” enter *Move tomorrow's AI workshop from 2 p.m. to 4 p.m.*, and select **Fill the form**. Show that the email preference stays selected even though the sentence did not mention email.
3. **Review (0:35–1:00).** Show the 2:00–3:00 → 4:00–5:00 preview, Calendar + schedule sheet, and 7 roster emails. Call out Rohan's overlapping 4:30 assignment and the participant availability note: unknown availability is not presented as checked.
4. **Approve (1:00–1:15).** Acknowledge the volunteer conflict and approve. The sample's controlled-failure scenario is on by default.
5. **Recover (1:15–1:50).** Show the verified Calendar step and Sheet failure. Retry the Sheet, then show that the timed-out email is reconciled from Sent instead of blindly resent; retry only the rejected email. Already verified steps are retained.
6. **Close (1:50–2:00).** Read the receipt: Calendar and Sheet updates verified; participant and volunteer email counts reflect actual simulated sends. Gmail acceptance does not mean a message was read or attendance confirmed.

Optional if time permits: before approval, change the start time after preview. The preview is marked out of date and approval stays disabled until you review the new time.
